BRAINSTOMRING 

In the AGENTS.md I brained stormed the project using the browser AI 

The concept started with a history website about telescopes, with history being split into two
eras, one pre space and one after 
The idea pitched was pre space to have a grunge style to show the rough but great progress and 
discoveries made with telescopes.
The post space era was supposed to have a Swiss style to relate to the cleanliness or really emptiness
of space and the discoveries made there. 

ORCHESTRATION PROCESS 

The orchestration process consistent of the sprint model, with each spec being an aspect of the
website that is split up from the AGENTS.md document. 

these are the specs made so far for this website: 
spec-01-two-era-telescope-history.md
spec-02-nextjs-quality-and-delivery-guardrails.md
spec-03-nextjs-parity-migration.md
spec-04-nextjs-production-readiness.md
spec-05-nextjs-deployment-and-release-readiness.md

These step taken can be to after created the spec, go through and run it then do a few quality 
check, I show the AI the step shown in the example doc and put it in the AGENTS.md so it know
to check whenever I ran a spec 

The AI described the process as 
spec → sprint → implementation → QA evidence → CI gates → release checklist → post-deploy smoke

BRAND ARCHETYPE 

Once I had the website foundation  done I asked the AI for which of the brand archetypes would fit the site. 
the best and Sage was picked. I made it set the tone to suit the brand.
